# 股票助手 Stock Helper

一个基于 Python 的股票管理工具，支持实时价格查询和投资盈亏计算。

## 功能特性

- **实时价格**: 获取最新股票价格和涨跌幅
- **投资管理**: 记录买入价和目标价，自动计算盈亏
- **分组管理**: 支持股票分组管理
- **灵活排序**: 支持按盈亏、分组排序
- **表格显示**: 美观的中文对齐表格展示

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行方式

```bash
python stock_helper.py
```

## 使用说明

### 主菜单操作

输入数字后立即执行，**无需按回车**：

| 数字 | 功能 |
| :--- | :--- |
| 1 | 刷新价格 |
| 2 | 切换排序方式 |
| 3 | 查看股票详情 |
| 4 | 添加股票 |
| 5 | 编辑股票 |
| 6 | 删除股票 |
| 0 | 退出程序 |

### 排序方式

按数字 `2` 切换排序方式：
- **盈亏排序**: 按盈亏百分比排序
- **分组+盈亏排序**: 先按分组排序，同组内按盈亏排序

### 添加股票

输入股票代码（如：600519）或名称（如：贵州茅台），然后设置推荐买入价、目标价和分组。

### 编辑股票

选择要编辑的股票序号，可修改推荐买入价、目标价和分组。

### 删除股票

选择要删除的股票序号，按 `y` 确认删除，其他键取消。

## 数据存储

股票数据保存在 `stocks.json` 文件中，包含：
- 股票名称和代码
- 推荐买入价
- 目标价
- 分组信息

## 技术实现

- **价格API**: 新浪股票行情接口
- **表格展示**: tabulate 库

## 重要提示

### 数据文件说明
- **stocks.json**: 正式股票数据文件，包含您的投资组合
- **test_stocks.json**: 测试数据文件，用于开发测试，不会影响正式数据

### 运行说明
- 程序默认读取 `stocks.json` 文件
- 测试时可使用 `StockManager('test_stocks.json')` 指定测试文件
- **请谨慎操作正式数据文件！**
