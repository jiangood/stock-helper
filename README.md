# 股票助手 Stock Helper

一个基于 Python 的股票管理工具，支持实时价格查询和投资盈亏计算。

## 功能特性

- **实时价格**: 获取最新股票价格和涨跌幅
- **投资管理**: 记录买入价和目标价，自动计算盈亏
- **分组管理**: 支持股票分组管理
- **灵活排序**: 支持按盈亏、分组排序
- **表格显示**: 美观的中文对齐表格展示
- **只读模式**: 以只读方式查看股票信息，防止误操作，自动刷新表格

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行方式

### 普通模式
```bash
python stock_helper.py
```

### 只读模式
```bash
python stock_helper.py --readonly
```

只读模式下会自动刷新显示股票表格，提供快捷键操作。

## 使用说明

### 只读模式快捷键

只读模式下自动刷新表格，按以下快捷键操作：

| 快捷键 | 功能 |
| :--- | :--- |
| R | 刷新价格 |
| S | 切换排序方式 |
| D | 查看股票详情 |
| Q | 退出程序 |

### 排序方式

按 `S` 切换排序方式：
- **盈亏排序**: 按盈亏百分比排序
- **分组+盈亏排序**: 先按分组排序，同组内按盈亏排序

### 添加/编辑/删除股票

在普通模式下操作，输入数字选择对应功能。

## 数据存储

股票数据保存在 `stocks.json` 文件中，包含：
- 股票名称和代码
- 推荐买入价
- 目标价
- 分组信息

## 技术实现

- **价格API**: 新浪股票行情接口
- **表格展示**: wcwidth 库（支持中文宽度对齐）

## 重要提示

### 数据文件说明
- **stocks.json**: 正式股票数据文件，包含您的投资组合
- **test_stocks.json**: 测试数据文件，用于开发测试，不会影响正式数据

### 运行说明
- 程序默认读取 `stocks.json` 文件
- 测试时可使用 `StockManager('test_stocks.json')` 指定测试文件
- **请谨慎操作正式数据文件！**
