# 股票助手 Stock Helper

一个基于 Python 的股票管理工具，支持实时搜索、价格查询和投资盈亏计算。

## 功能特性

- **实时搜索**: 支持股票名称和代码的模糊搜索
- **实时价格**: 获取最新股票价格和涨跌幅
- **投资管理**: 记录买入价和目标价，自动计算盈亏
- **表格显示**: 美观的中文对齐表格展示

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行方式

```bash
python stock_helper.py
```

## 使用说明

### 主菜单操作

1. **添加股票**: 搜索并添加新股票到自选列表
2. **编辑股票**: 修改已添加股票的买入价、目标价和备注
3. **删除股票**: 从自选列表中移除股票
4. **搜索股票**: 实时搜索股票（支持模糊搜索）
5. **刷新价格**: 更新所有股票的实时价格
6. **排序设置**: 按名称、价格、涨跌幅等排序
7. **查看详情**: 查看股票详细信息

### 搜索功能

- 支持股票名称搜索（如：茅台、招商）
- 支持股票代码搜索（如：600519、000858）
- 支持模糊匹配

## 数据存储

股票数据保存在 `stocks.json` 文件中，包含：
- 股票名称和代码
- 买入价（支持两个买入价）
- 目标价（支持两个目标价）
- 备注信息

## 技术实现

- **搜索API**: 新浪股票搜索接口
- **价格API**: 新浪股票行情接口
- **表格展示**: tabulate 库

## 重要提示

### 数据文件说明
- **stocks.json**: 正式股票数据文件，包含您的投资组合
- **test_stocks.json**: 测试数据文件，用于开发测试，不会影响正式数据

### 运行说明
- 程序默认读取 `stocks.json` 文件
- 测试时可使用 `StockManager('test_stocks.json')` 指定测试文件
- **请谨慎操作正式数据文件！**
