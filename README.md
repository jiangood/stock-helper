# 股票助手 Stock Helper

## 访问地址

- **在线首页：** [https://jiangood.github.io/stock-helper/](https://jiangood.github.io/stock-helper/)
- **个股详情示例（002408）：** [打开个股详情](https://jiangood.github.io/stock-helper/stock.html?code=sz002408)

首页提供股票池监控看板，支持实时行情、搜索、分组和纪律筛选；个股详情页可查看行情、K 线、估值与交易辅助面板。

## 本地预览

```bash
python -m http.server 8089
```

打开 http://localhost:8089/

## 生意 / 商品数据

「生意」选项卡不要求用户手工录入价格。GitHub Actions 工作日定时运行 `scripts/fetch_business_data.py`，更新 `data/business-data.json`，首页自动读取最新缓存。主要数据源包括生意社现货/期货基差数据、东方财富现货与股票数据，以及新浪财经商品期货行情；卡片会区分现货与期货口径并显示数据日期/来源。

- 自动抓取是定时更新，不是逐笔实时行情；期货连续报价只作市场参考，不等同于现货成交价。
- 如果某个品种没有可靠匹配到公开数据源，会显示「等待可靠数据源」，不会生成虚构价格。
- 商品涨价不必然让关联上市公司受益，仍要结合公司实际业务占比、成本、库存、供需和盈利质量判断。
- 自动抓取任务与运行状态可在 [GitHub Actions](https://github.com/jiangood/stock-helper/actions/workflows/business-data.yml) 查看。

## 全球资产

底部「全球资产」页展示黄金、BTC、ETH、日经 225、纳斯达克 100、标普 500 和 VIX 恐慌指数。页面增加按日涨跌幅排序的排行卡、各资产近一个月迷你趋势，以及近一周 / 近一个月归一化趋势对比（各序列起点设为 100，便于比较相对变化而非绝对价格）。抓取脚本为各资产保存近一个月日线历史；历史点不足时明确提示，不补造数据。VIX 上升通常表示期权市场隐含的预期波动增强，不是市场涨跌方向预测。行情通过 GitHub Actions 约每 30 分钟抓取并缓存，实际调度可能延迟；这是公开行情参考，不是逐笔实时行情。各市场币种和交易时段不同，报价失败时不生成模拟价格，页面会显示最近有效报价及更新时间。

## 鳄鱼纪律

`croc.js` 把资料里可量化的规则做成页面共用工具：

- **净资产八折**：PB ≤ 0.8 标记「八折」，PB < 1 标记「破净」
- **200 亿市值**：总市值 ≤ 200 亿才算通过「纪律」项，超过则扣一项
- **30 倍估值锚**：PE(TTM) 在 0–30 之间才算通过，> 30 或亏损均未过
- **不买 ST / 亏损**：首页旗标 + 体检风险清单
- **入场区 / 重仓区**：现价 ≤ 重仓价 / 入场价
- **卖其疯狂**：日 K 连续涨停 ≥ 3 或涨停打开时提示清仓纪律
- **历史分位**：月 K（最多 240 根）价格分位，辅助判断长周期位置
- **纪律全过**：非 ST、非亏损、PE ≤ 30、市值 ≤ 200 亿、PB < 1 五项自动筛选，首页「纪律」列显示通过数（全过 / 4/5 / 3/5…），可按「纪律全过」「全过 + 买点」筛选

底部「简报」页整合指数行情、股票池涨跌温度、按分组统计的板块强弱、持仓市值与浮动盈亏，以及原机会雷达和量化纪律名单；原首页简报按钮已移除。持仓统一从`data/holdings.json` 读取，简报与风险中心共用该文件；网页不再录入或保存持仓，修改持仓数量/成本、组合总资产、风险预算、风险退出参考价后，需提交 JSON 并等待 GitHub Pages 更新。该仓库公开，因此文件内容公开可见；不要放入不希望公开的信息。`🩺` 检查 `data/stocks.json` 的结构问题（代码重复、买点区间写反、止盈顺序、ST/亏损）。

详情页「鳄鱼纪律」中的**持仓成本**统一从公开 `data/holdings.json` 读取，用于计算翻倍卖点、三倍目标与浮盈；修改成本请编辑 JSON 并提交，不在网页或浏览器保存；「资源股现价估值」按 `(P−C)×Q×折扣×PE` 粗算合理市值，同样只保存在本机。

> 本机浏览器仍保存资源股估值参数 `croc-valuation:<code>`；持仓数量与成本不再保存在浏览器。

## 做T / 补仓

详情页两张面板均为纯前端计算，数据缺失只降级展示，不阻塞主流程：

- **做T（日内）**：现价对 VWAP 的偏离、15 分 MFI、量能（近 3 根 ÷ 前 12 根），外加单边行情过滤；给出正T / 倒T 参考价位与默认 2% 差价目标。分钟数据约 20 个交易日。
- **补仓（日线）**：① 到支撑（POC / 价值区下沿 / 重仓价 ≤3%）② 资金确认（MFI 底背离，或 MFI<20 后回升上穿）③ 趋势过滤（现价 > MA20，或 OBV 20 日不创新低）。3/3 才提示分批补仓，2/3 小仓试探。
- 筹码分布按日 K 成交量均匀摊到价格区间，是**近似**值；所有结论仅辅助参考，不构成投资建议。

拼音搜索示例：`tk` / `tksw` / `tiankang` / `kangsheng` 都能命中「天康生物」，`qitian` 命中别名「齐天大圣」。

## 行情 SDK

```js
const q = new StockQuotes.Client({ timeout: 8000, cacheTTL: 1000 });
const data = await q.fetch(['sz002408', 'sh600519']);
// { sz002408: { code, name, price, prevClose, change, todayChange, divYield, time } }

// 单只详情（含估值、52 周高低）
await q.fetchDetail('sz002408');

// K 线、分钟 K 与分时
await q.fetchKline('sz002408', { period: 'day', count: 250, adjust: 'qfq' });
await q.fetchMinuteKline('sz002408', { period: '15', count: 320 });   // 约 20 个交易日
await q.fetchTrends('sz002408');

StockQuotes.marketSession();   // 'open' | 'pre' | 'lunch' | 'closed' | 'holiday'
StockQuotes.isTrading();       // 是否处于需要刷新行情的时段
```


## 生意选项卡数据口径

- 商品价格：展示自动抓取的现货/期货参考价与可用历史趋势。
- 供需辅助指标：尝试抓取交易所期货仓单库存；它不等同于全行业厂家库存、港口库存或社会库存，页面会明确标注口径。
- 产业链辅助信息：自动展示数据源列示的生产商、下游用户名称；这类名单不代表股票持股关系，也不保证构成直接供销关系。
- 原料成本观察：自动抓取氧化铝、合成氨、硫酸、钛精矿、动力煤的公开市场参考价与可用历史趋势。它们仅是成本方向代理指标，不等于企业实际采购成本、单位成本或毛利；缺失时明确显示待获取。
- 简易供需观察：结合商品参考价格与期货仓单短期变化，显示方向性提示。该提示是规则化观察线索，不是统计模型或交易信号；仓单不等于全行业库存，需与厂家/港口库存、开工率和需求交叉验证。
- 同日历史基差：在现货与期货参考价具有同一日期时，展示现货减期货的基差与基差率；不会拿不同日期的现货和实时期货拼算基差。
- 未获取到可靠数据时会显示缺失状态，不用人工填值或估算值补齐。
