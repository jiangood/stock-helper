价值投资

Value Investing

在时间的河流中，寻找确定性的锚点

01

安全边际

以低于企业内在价值的价格买入，为判断失误留出缓冲空间。安全边际是价值投资的基石。

02

能力圈

明确自己懂什么、不懂什么。在能力圈内投资，不追逐热点，不涉足未知领域。

03

市场先生

市场是你的仆人，不是你的向导。利用市场的情绪波动，而非被其左右。

04

长期主义

买入股票就是买入企业的一部分。与优秀企业共同成长，让时间成为你的朋友。

05

经济护城河

寻找具有持久竞争优势的企业。护城河越宽，企业越能抵御竞争，长期价值越稳固。

06

集中投资

少即是多。押注于你最确定的机会，深度研究带来信心，信心带来持有定力。
