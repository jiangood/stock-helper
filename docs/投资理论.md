第一节 从“鳄鱼”到投资者：耐心是唯一的秘诀
本节开宗明义，揭示了“鳄鱼”投资法名称的来源及其核心精神。

鳄鱼的生存智慧：
鳄鱼在地球上存活了超过2亿年，历经多次物种大灭绝而未被淘汰，其生存策略堪称“顶级策略”。
核心策略是 “低消耗，平时不动” 。它不主动追逐猎物，只在猎物进入绝对攻击范围的确定性时刻，才迅猛出击，一击致命。
这种策略的特点是：放弃大部分机会，只做100%确定的交易；大部分时间一动不动，但一次成功捕猎就能获得维持很久的能量。
与投资模式的完美契合：
放弃细小机会：正如鳄鱼不追逐所有小鱼，投资者应放弃市场中大量看似诱人但不确定的短线机会、热点题材。这对应了投资原则中的“放弃大量细小的机会”。
等待确定性一击：投资如同捕猎，只在“猎物到嘴里”——即市场出现价格远低于价值的确定性定价错误时，才重仓出击。这对应了“寻找罕见的、确定性的、风险收益比极高的股票”。
低消耗与耐心：平时“一动不动”，意味着买入后长期持有，不做频繁交易，不预测短期波动，以极低的心理和交易成本（“低消耗”），等待价值兑现。这对应了“长线价值投资”和“耐心”。
赚一次，吃很久：像鳄鱼一次捕猎能吃很久一样，一次成功的投资（如一只股票翻数倍）所带来的利润，足以让你安心等待下一个数年一遇的大机会。
对投资者的启示：
剧烈运动不一定健康：在市场中频繁交易、追逐热点，消耗巨大且成功率低，如同不停奔跑捕猎的小型动物，寿命和成功率远不及鳄鱼。
顶级策略是“反人性”的：这种策略要求克服人类天性中的贪婪（想抓住所有机会）、恐惧（害怕错过）和不安（无法忍受枯燥等待），从而达到“戒能生定，定而生慧”的境界。
第二节 投资十六字真言：专注商品、立足周期、低位买入、长期持有
本节将鳄鱼哲学具体化为指导一切投资实践的十六字方针。

专注商品：
定义：将投资范围严格限定在与大宗商品（资源）相关的领域。这是因为商品（如石油、金属、农产品）是人类文明的基础，其需求跨越周期始终存在。
逻辑：商品价格是全球供需的反映，相对透明，不易被个别公司操纵。通过投资商品股，等于间接囤积了无法被央行“印刷”出来的实物生产资料。这是占有财富最本质的形式。
立足周期：
定义：承认并利用万物皆有的周期性规律。所有行业、经济体、资产价格都遵循“萧条—复苏—扩张—狂热—衰退”的循环。
逻辑：投资的核心不是预测，而是识别周期阶段。在萧条末期或复苏初期（行业最差、人人抛弃时）介入，在狂热期（人人追捧时）退出。周期力量超越任何个人或机构的意志。
低位买入：
定义：不是指股价绝对值低，而是指价格相对于内在价值处于显著低估的位置。核心标准包括“净资产的八折”、“产品已涨价而股价未动”、“长期历史低位”等。
逻辑：这是实现“用五毛钱买一元钱价值”的唯一途径。买的足够低，提供了巨大的安全边际，使得后续波动可以无视，敢于重仓，并能从容等待。
长期持有：
定义：以“年”为单位的持股周期。接受“95%的时间不涨，5%的时间快速拉升”的客观规律。
逻辑：价值的兑现、周期的运行都需要时间。长期持有是跨越市场噪声、克服情绪波动、让复利发挥作用的关键。“不动”本身是最重要的一种操作。
